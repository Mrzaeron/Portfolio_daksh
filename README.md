# Daksh Singla Portfolio

A personal portfolio website for Daksh Singla, highlighting his work, skills, and contact information.

## Overview

This is a lightweight static portfolio built with HTML, CSS, and JavaScript. It features a dark-mode toggle, animated hero text, responsive sections, and social links to GitHub, LinkedIn, LeetCode, X, and YouTube.

## Tech Stack

- HTML
- CSS
- JavaScript

## Features

- Responsive portfolio layout
- Modern terminal-inspired design
- Dark mode toggle
- About, Skills, Projects, and Contact sections
- Quick access to social profiles and email

## Run Locally

You can open `index.html` directly in a browser, or serve it locally:

```bash
python -m http.server 8000
```

Then open:

```bash
http://localhost:8000
```
